# ⚡ Экспресс-ДЗ

Сайт с ответами на домашку. Работает полностью сам: **открыл сайт — он сам нашёл
фото в папках предметов и сам показал дату и номер**. Никаких программ, батников,
серверов и лишних кнопок. Чистый HTML + CSS + JavaScript.

## Как открыть

Двойной клик по **index.html** — всё. Лучше всего открывать в Chrome (или
Яндексе / Edge — они тоже подойдут).

## Как добавить фото

1. Закинь фото (или скриншот) в папку нужного предмета — например, `Алгебра/`.
2. Назови файл **дата + номер** (два варианта, оба работают):

| Имя файла | Что покажет сайт |
|---|---|
| `01122026(1).png` | дата **1 декабря 2026**, номер **№1** |
| `220920261.png` | дата **22 сентября 2026**, номер **№1** |

   - Первые 8 цифр — день (2), месяц (2), год (4). Дальше номер — в скобках
     или просто цифрой.
   - Расширение: `.png`, `.jpg`, `.jpeg`, `.webp` — или вообще без расширения.

Больше ничего делать не нужно: сайт сам находит фото по имени, сам показывает
дату над фотографией и сам выстраивает порядок: **чем новее дата — тем выше**,
внутри одной даты **меньший номер — выше**.

Если по предмету фото нет — написано **«ДЗ нет»**.

## Как увидеть новое фото

Сайт проверяет папки сам:
- нажми **«Выбрать»** под меню предмета — фото появится сразу;
- или просто вернись на вкладку / подожди ~20 секунд;
- или нажми **F5** (обновить страницу) — самый быстрый способ.

## Что важно знать

Браузер не даёт странице читать список файлов в папке напрямую, поэтому сайт
перебирает имена по шаблону «дата + номер». Правила простые:

- называй файлы по шаблону `ДДММГГГГ(номер)` или `ДДММГГГГномер` — и фото
  найдётся само;
- сайт ищет даты за учебный год (1 сентября — 30 июня) плюс 45 дней вокруг
  сегодняшнего дня;
- номера — от 1 до 15;
- если файл назван по шаблону, но не показался — нажми «Выбрать» или F5.

## Файлы сайта

```
index.html            — страница
style.css             — стили (адаптив: телефон + компьютер)
script.js             — логика (меню, поиск фото, сортировка, автообновление)
<папки предметов>/    — сюда кидаешь фото
```
